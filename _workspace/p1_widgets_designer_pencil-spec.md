## 플로우

1. 작은 위젯에서 오늘 지출 0원과 이번 달 지출을 각각 확인한다.
2. 중형 위젯에서 스트릭과 빠른 기록 진입점을 확인한다.
3. 잠금화면 프리셋은 금액을 노출하지 않는다.
4. 프리셋 탭 후 Face ID를 통과하면 기존 기록 화면에 금액·카테고리를 프리필한다.
5. 사용자가 값을 확인하고 저장한다. 즉시 저장은 하지 않는다.

## 상태

- 빈 데이터: 0원과 시작 액션
- 오래된 데이터: 마지막 동기화 시각과 업데이트 필요
- 인증 취소: 저장 없음
- 오프라인: 로컬 큐 저장 후 동기화
- 중복 탭: 멱등 처리
