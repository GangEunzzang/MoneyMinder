PRODUCT SPEC
기획 문서
가계부 base + 무지출 미션 레이어
한 줄 정의
매일 3초로 지출을 기록하는 가계부에, 무지출을 게임처럼 이어가는 미션 레이어를 얹은 앱
타겟
20~30대 · 지출 관리는 하고 싶지만 가계부는 늘 작심삼일로 끝나는 사람. 숫자·그래프보다 성취감·습관 형성에 반응하는 사용자.
핵심 가치
3초 기록
결제처·카테고리 자동추천 + 키패드로 즉시
무지출 미션
안 쓴 날이 스트릭·배지로 쌓이는 게임화
공유·자랑
연속 기록을 카드로 만들어 SNS 공유
정보 구조 (IA) — 5 탭
홈
이번달 지출·예산·무지출 스트릭 한눈에 + 오늘 무지출 인증
내역
리스트/달력으로 거래·무지출일 조회, 검색·필터·상세
＋ 기록
지출/수입 3초 입력 (세그먼트·키패드·카테고리)
미션
스트릭·주간 미션·배지·무지출 캘린더·공유
전체
예산·카테고리·알림·프로필·데이터·테마 설정
핵심 플로우
온보딩 스플래시 → 가치소개 → 로그인(카카오/애플/구글) → 초기 예산 → 홈
지출 기록 홈 ＋ → 지출/수입 → 키패드 금액 → 카테고리 → 저장 → 토스트 → 홈 반영
무지출 미션 홈 '오늘 무지출 인증' → 스트릭 +1 → 축하(컨페티) → 공유 카드
내역 조회 홈 → 내역 → 리스트/달력 → 필터 → 거래 상세 → 수정/삭제
핵심 정책
· 무지출 판정
하루 지출 합계 0원이면 무지출 성공 (자정 기준 확정)
· 스트릭
연속 무지출일. 하루라도 지출하면 0으로 리셋, 최장 기록은 별도 보존
· 예산
월 예산 대비 사용률 표시. 초과 시 게이지 red + 무지출 도전 유도
· 주간 미션
주 N일 무지출 목표(기본 4일). 요일 도트로 진행 표시
